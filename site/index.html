The honest detail

If the agent says it's done, and no test has passed since the last edit —
a gremlin hides behind it.

No other visualiser checks the claim against the evidence. Agent Theatre shows the passing test count as a chip when it exists, and the gremlin when it doesn't. Nothing is invented; every beat traces back to an event.

Every character is drawn by one procedural routine from a short spec — a shape, a topper, a pair of eyes, a palette. No sprite sheets. Their light shows their mood.

How it works.

  1. 01

    Events

    Claude Code hooks (live) or the session transcript (replay), normalised into one small schema: read_file, edit_file +n −m, run_command, test_result, subagent_start… Counts and paths. Never contents.

  2. 02

    Stage

    The file tree becomes a deterministic arrangement — six layouts, chosen from the repo and the stage. Every file the session touches is always placed.

  3. 03

    Director

    Events become beats — walk, read, build, run tests, spawn gremlin, chase, celebrate — with a mood: curious, focused, lost, happy.

  4. 04

    Renderer

    Isometric WebGL. The camera follows the character; the whole stage appears only to open, celebrate and close, so it never gets cluttered. prefers-reduced-motion respected.

Privacy. Not a setting.

Agent Theatre runs entirely on your machine and talks only to 127.0.0.1. Events carry repo-relative paths, line counts, a command's first word and a classified intent — never file contents, prompts, command bodies or search queries. A test plants marker strings in all of those and asserts zero leaks. Hooks install non-destructively with a backup, and uninstall byte-for-byte.

Two commands.

$ npx agent-theatre hooks install
$ npx agent-theatre

Opens the stage for the repo you're in. Run Claude Code in another terminal and watch. npx agent-theatre replay plays back any past session. Node 22+.
