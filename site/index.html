Agent Theatre turns a Claude Code session into an animated scene. Your repo becomes a stage: folders are districts, files are buildings, test files are beacons. The agent is a character who walks to the files it reads, builds on the files it edits, runs tests at the beacons — and chases bug gremlins when they fail.

And one honest detail no other visualiser has: if the agent says the job is done but no test has passed since the last edit, a gremlin hides behind it.

How it works

  1. Events. Claude Code hooks (live) or the session transcript (replay) are normalised into a small, product-agnostic event schema: read_file, edit_file +n −m, run_command, test_result, subagent_start, waiting_for_user… Counts and paths only — never contents.
  2. Stage. The repo's file tree becomes a deterministic arrangement — one of six layouts chosen from the repo and the stage — so the same project is a ring island in one set and a terraced spine in another, and always the same in the same set.
  3. Director. Events become scene beats — walk, read, build, run tests, spawn gremlin, chase, celebrate — with a mood: curious, focused, lost, happy.
  4. Renderer. Isometric, one key light, long soft shadows, bloom only where something glows. No linear tween exists in the codebase; a test makes sure. The camera follows the character; the whole stage appears only to open, celebrate and close.
  5. Sound. Every beat has a sound and every stage has its own voice and ambience — all synthesized at runtime, no audio files. Effects and ambience toggle separately.

Privacy, precisely

  • Runs entirely on your machine. No account, no telemetry, no network calls except to 127.0.0.1.
  • Events carry repo-relative paths, line counts, a command's first word and a classified intent. Never file contents, prompts, command bodies or search queries. A test plants marker strings in all of those and asserts zero leaks.
  • Paths outside the repo appear as //ext/<name>; your home directory as ~/.
  • Hooks are installed into ~/.claude/settings.json non-destructively with a backup, and agent-theatre hooks uninstall reverses it byte-for-byte. The hook always exits 0 and never blocks a tool call.

Install

CLI

cd your-repo
npx agent-theatre hooks install   # once
npx agent-theatre                 # opens the stage; run Claude Code in another terminal
npx agent-theatre replay          # pick any past session of this repo

Node 22+. Works with the Claude Code CLI, desktop app and IDE extensions — anything that runs hooks.
