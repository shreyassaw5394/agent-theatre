InstallHow do I get it?

Two commands in your repo: npx agent-theatre hooks install, then npx agent-theatre. Run Claude Code in another terminal and watch. Node 22 or newer.

  • npm npx agent-theatre
  • Claude Code plugin /plugin install agent-theatre --marketplace shreyassaw5394/agent-theatre
  • Homebrew brew install shreyassaw5394/tap/agent-theatre
  • VS Code search “Agent Theatre” in Extensions
  • Cursor, Windsurf, VSCodium install the .vsix from the latest release
  • Other agents (MCP) npx agent-theatre init
PrivacyDoes anything leave my machine?

No. Agent Theatre runs locally and talks only to 127.0.0.1. Events carry repo-relative paths, line counts, a command's first word and a classified intent, never file contents, prompts, command bodies or search queries. A test plants marker strings in all of those and checks none leak. Hooks install with a backup and uninstall cleanly. Privacy page.

ReplayCan I watch a past session?

Yes. npx agent-theatre replay lists this repo's past sessions, newest first, and plays any of them.
